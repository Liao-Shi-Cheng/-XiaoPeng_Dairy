关于小朋日记

小朋日记是一个给自己留一点空间的个人日记工具。你可以记录日常、整理心情，也可以在以后重新翻看曾经的自己。

✎ 认真记录标题、正文和心情都可以按自己的习惯填写。
⌕ 轻松回看通过关键词或心情找到过去的记录。
⇩ 留下备份将日记导出为 Markdown 文件，方便保存。
◐ 三种风格汽水浅色、黑色与原木色，可以随时切换。

小提醒：请勿在日记中填写密码、银行卡号等敏感信息。当前页面通过后端接口保存数据，是否能成功使用取决于后端服务是否已启动。

PRIVACY · AI

AI 情绪分析说明

发送内容：只有在你明确同意并点击“分享今天给鲸鱼娘”后，今天这一篇日记的标题和正文才会发送到已配置的 DeepSeek API 用于情绪分析；历史日记不会被上传。

使用目的：分析结果仅用于选择鲸鱼娘的情绪形象，并生成一句不超过 30 字的回应，不会写入你的日记正文。

数据边界：API Key 只保存在后端环境变量 DEEPSEEK_API_KEY 中，不会发送到浏览器。请不要在日记里填写密码、银行卡号等敏感信息。

你的选择：不启用 AI 时，日记功能仍可正常使用，你也可以随时手动切换鲸鱼娘的情绪。你可以在当前浏览器中撤回同意，撤回后不会再发送新的分析请求。
